BRING YOUR TEAM’S TIMETABLE

Import weekly schedules

Update the whole team in one step: extract or export the complete timetable, convert it to this CSV format, then import the single file. Each row is one weekly class or busy time.

name,day,start,end,complete,required,school,department

day: Monday–Saturday · times: 24-hour HH:MM
complete / required: true or false
school / department: optional affiliation columns

For faculty with no classes, leave day, start and end blank and set complete to true. Only mark complete when the full weekly schedule is included.

Imported schedules stay in this browser and are never uploaded to this website or GitHub. Export a CSV to move your timetable to another computer. Import one complete CSV to update the whole team.
