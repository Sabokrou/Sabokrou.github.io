1. Variables and basic types

A variable gives a name to a value. Use clear names that explain what the value means.

student_name = "Aziza"       # string: text
completed_labs = 3           # integer: whole number
average_score = 82.5         # float: decimal number
submitted = True             # boolean: True or False

print(student_name, completed_labs, average_score, submitted)

2. Comparisons and decisions

Comparisons produce True or False. An if statement chooses what to do.

score = 67

if score >= 60:
    result = "pass"
else:
    result = "review and try again"

print(result)
Exercise B

Add a third result: "excellent" for scores of 85 or above. Test your code with 52, 67, and 91.

3. Lists and loops

A list stores several values. A loop applies the same action to each value.

scores = [72, 85, 61, 90]

total = 0
for score in scores:
    total = total + score

mean_score = total / len(scores)
print(mean_score)
Exercise C

Count how many scores are at least 60. Then print the fraction that passed and explain it in a sentence.

4. Functions

A function gives a name to a reusable operation. Inputs are parameters; return sends the result back.

def pass_label(score, threshold=60):
    if score >= threshold:
        return "pass"
    return "not yet"

print(pass_label(72))
print(pass_label(72, threshold=80))
Exercise D

Write percentage(part, whole). It should return 100 * part / whole. Test it with 18 out of 24 students.

5. NumPy arrays and pandas tables

NumPy works with numerical arrays. pandas works with labelled tables called DataFrames.

import numpy as np
import pandas as pd

scores = np.array([72, 85, 61, 90])
print("Mean:", scores.mean())

students = pd.DataFrame({
    "name": ["Ali", "Aziza", "Dilshod"],
    "score": [72, 85, 61]
})

print(students.head())
print(students["score"].mean())
